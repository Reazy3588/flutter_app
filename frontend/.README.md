# 🛒 E-Commerce Frontend

Flutter-based E-Commerce Mobile App.

## 🚀 Features

- 🏠 Home with product categories
- 🔍 Search & Filter products
- 🛒 Cart & Checkout
- ❤️ Wishlist
- 👤 User Profile
- 💳 ABA PayWay Payment (KHQR)
- 📦 Order Tracking

## 🛠️ Tech Stack

- Flutter
- Dio (HTTP Client)
- Shared Preferences
- Google Sign-In
- QR Flutter

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (>= 3.0)
- Dart SDK
- Android Studio / VS Code

### Installation

```bash
git clone https://github.com/username/ecommerce-frontend.git
cd ecommerce-frontend
flutter pub get
flutter run
```
